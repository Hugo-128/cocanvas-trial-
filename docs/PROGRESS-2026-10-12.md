```bash
# 测试（服务起着才能跑 E2E）
pnpm typecheck
cd apps/web && pnpm test        # 集成测试
pnpm test:e2e                   # E2E（脚本内会先检查服务）
```

**本机环境注意（重要，踩过的坑）**：
- 装依赖必须 `pnpm install --ignore-scripts`（esbuild postinstall 会被本环境
  Node 的 spawn 限制卡死；二进制本身可用）
- 若 `pnpm install` 报 "Already up to date" 但不装东西：lockfile 可能被写成
  空壳。恢复：`rm -rf node_modules apps/*/node_modules packages/*/node_modules
  pnpm-lock.yaml && pnpm install --ignore-scripts`
- E2E/curl 访问 localhost 要清代理：`HTTP_PROXY= HTTPS_PROXY= http_proxy=
  https_proxy= NO_PROXY='*' <命令>`（本机有 127.0.0.1:2155 代理变量）
- 浏览器连 ws 用 127.0.0.1 不用 localhost（::1 问题）

### P1 — Phase 1 启动前要做的设计（写进 DEVLOG 再动代码）

- PG schema（Alembic 或纯 SQL，paperscope 用 Alembic，可借鉴）：
  `docs(id, title, created_at, updated_at)` / `updates(id, doc_id, update bytea,
  created_at)` / `doc_members(doc_id, user_id, role)`
- 落库失败恢复：updates 先写 PG 再广播，失败进重试队列（指数退避）；
  重启后加载 = snapshot（Phase 4 才有，Phase 1 先全量 updates 重放）
- 幂等预研：Yjs update 本身应用幂等；PG 侧靠 (doc_id, update hash) 唯一索引
- 验收（AGENTS.md）：杀 server 重启 → 刷新页面 → 内容一致；两人同时编辑不冲突
